# hospital-emergency-excel-

## purpose of the project 

we need to create a hospital Emergency Room Analysis dashboard in excel to improve efficiency and provide useful insights .

this dashboard will help stakeholders monitor,analyze ,and make better desicions for managing patients and improving services 


## KPI'S Requirement 

1) number of patients :-
   
   count the total no of patients visiting the Emergency room each day ,
   
   show a daily trends with an area sparkline to spot patterns like busy days or            seasonal trends

2) average wait time :-

   find the average time patients wait to see a medical professional(doctors) .
   
    use an area sparkline to track daily changes and highlighted days with longer 
    wait 
    times that might need improvements

   3) patients satisfaction score :-
      check the average daily satisfaction score of patients to assess service       
      quality .
       use an area sparkline to show trends ,spot drops in satisfaction ,and lint  
       hem to challenges


  charts to create :-
   1) patient admission status :- show how many patients wew admitted vs not admitted
   2) patient age distribution:- group patients by age
   3) timeliness:- measure the percentage of patients seen within 30 minutes
   4) gender analysis :- display the no of patients by gender
   5) department referrals :- check which departments patients are referred to the most
